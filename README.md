# Artículos de Pablo Santana

Web sencilla de artículos, publicada con GitHub Pages.

- `index.html`: portada, un lienzo vacío con la frase de San Pablo (2 Tim 1,12).
- `articulos/index.html`: la lista de artículos.
- Cada artículo vive en su propia carpeta, con un `index.html` dentro. Así la dirección queda limpia: `/dios-en-las-tragedias/`.
- `estilos.css`: el diseño común de todas las páginas.

Para añadir un artículo: crear una carpeta nueva con su `index.html` (copiando la estructura de uno existente) y añadir una entrada en la lista de `articulos/index.html`.
